# TB Patient Dataset: Capstone Analysis

## Project Overview

This project was completed as part of an R programming course capstone. It involves exploring clinical-parameter data from a tuberculosis patient dataset using R and Quarto.

## Objectives

- Clean and prepare the dataset for analysis.
- Calculate descriptive statistics for patient age and assessment delay.
- Examine cough prevalence and patient distribution by district and gender.
- Assess the distribution of patient age.
- Categorise patients based on the number of abnormal clinical parameters.
- Compare derived risk categories with medical officer classifications.
- Conduct an exploratory data-quality check of recorded abnormal-parameter counts.

## Tools Used

- R
- RStudio
- Quarto
- tidyverse
- janitor
- readxl

Claude was used as a supplementary tool for coding assistance during the project.

## Data Privacy

The original patient-level dataset is not included in this repository. The analysis is shared subject to the applicable data-sharing permissions and privacy requirements.
